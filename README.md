# לומדים בבית 📚

אפליקציית לימוד וחזרה לילדים: הלל (ד׳), נירי (ה׳), איתמר (ח׳) ודני (גן חובה).
אפליקציית ווב אחת עם פרופיל לכל ילד, שרצה בטלפון, בטאבלט ובמחשב. כל ההתקדמות נשמרת בגיט ועוברת בין מכשירים.

## מה כבר עובד
- **לוח הכפל** (הלל ונירי)
  - **ללמוד ולראות**: כל תרגיל ב-5 דרכי המחשה: קבוצות, מערך, קפיצות על ציר המספרים, חיבור חוזר, שטח ופירוק (למשל 7×8 = 7×5 + 7×3).
  - **תרגול יומי**: 12 תרגילים שנבחרים לפי חזרה מרווחת. תרגיל שטועים בו חוזר מהר, ותרגיל שכבר יודעים חוזר לעיתים רחוקות. כל טעות מציגה מיד המחשה עם כפתור "תראו לי בדרך אחרת".
  - **המפה שלי**: טבלת 10×10 שנצבעת מאדום לירוק.
- **אותיות וקריאה באנגלית** (הלל ונירי)
  - **מכירים את האותיות**: כל אות ב-4 דרכים: תמונה ומילה, איך היא נשמעת (בעברית: B ← בּ), גדולה וקטנה בכמה גופנים (כולל טיפים ל-b/d/p/q), וכתיבה עם האצבע על המסך. יש השמעה קולית באנגלית.
  - **תרגול אותיות**: שומעים ובוחרים, מתאימים גדולה לקטנה, ומזהים באיזו אות מתחילה מילה. המסיחים הם אותיות שקל להתבלבל ביניהן. סדר הלימוד: S A T P I N, כמו בשיטות הפוניקה.
  - **מחברים צלילים**: c-a-t עם הצליל העברי מתחת לכל אות, ואז "לחבר!" מראה cat, תמונה, הקראה ופירוש. 32 מילים.
  - **מילים שרואים הרבה**: 40 מילים נפוצות (the, is, and…) עם הקראה ופירוש.
  - **תרגול קריאה**: קוראים מילה ובוחרים תמונה, שומעים ובוחרים איך כותבים, ומתאימים מילה לפירוש שלה.
- **כניסה עם קוד**: לכל ילד קוד אישי ולהורה סיסמה. ההתקדמות נשמרת במכשיר וגם בקובץ `progress/<ילד>.json` בענף `progress` בריפו, ועוברת בין מכשירים.

## הקמה (פעם אחת)

### 1. אתר
ב-GitHub: **Settings → Pages → Deploy from a branch → `main` / root**.
אחרי דקה האתר זמין בכתובת `https://guyos2.github.io/school/`. בטלפון אפשר לבחור "הוספה למסך הבית" והוא ייראה כמו אפליקציה.
> אם הריפו פרטי, GitHub Pages דורש מנוי GitHub Pro. אפשרות אחרת היא לפרסם דרך Cloudflare Pages (חינם).

### 2. טוקן לגיט
ב-GitHub: **Settings → Developer settings → Fine-grained tokens → Generate new token**
- Repository access: רק `guyos2/school`
- Permissions: **Contents: Read and write**

### 3. שרת סנכרון (Cloudflare Workers, חינם)
```bash
cd worker
npx wrangler login
npx wrangler secret put GH_TOKEN       # הטוקן מסעיף 2
npx wrangler secret put TOKEN_SECRET   # מחרוזת אקראית ארוכה, למשל 40 תווים
npx wrangler secret put USERS          # המשתמשים והקודים, ראו למטה
npx wrangler deploy
```
הערך של `USERS` (קוד לכל ילד וסיסמה להורה):
```json
{"hillel":"1234","niri":"5678","itamar":"2468","dani":"1357","parent":"סיסמה-חזקה"}
```
הפקודה `deploy` מדפיסה כתובת בסגנון `https://school-sync.<שם>.workers.dev`. את הכתובת שולחים ל-Claude, או רושמים אותה בעצמכם ב-`content/config.json`. מאותו רגע כל מכשיר יבקש כניסה.

### 4. בכל מכשיר
פותחים את האתר, לוחצים על התמונה ומקלידים את הקוד. המכשיר זוכר את הכניסה לשנה.
- **ילד** רואה רק את עצמו ונכנס ישר לפרופיל שלו.
- **הורה** רואה את כל הילדים.
- יציאה מהחשבון: ⚙️ → "יציאה מהחשבון".
- כדי לנתק את כל המכשירים בבת אחת, מחליפים את `TOKEN_SECRET`.
