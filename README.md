# לומדים בבית 📚

אפליקציית לימוד וחזרה לילדים: הלל (ד׳), נירי (ה׳), איתמר (ח׳) ודני (גן חובה).
אפליקציית ווב אחת עם פרופיל לכל ילד, שרצה בטלפון, בטאבלט ובמחשב. כל ההתקדמות נשמרת בגיט ועוברת בין מכשירים.

## מה כבר עובד
- **לוח הכפל** (הלל ונירי)
  - **ללמוד ולראות**: כל תרגיל ב-5 דרכי המחשה: קבוצות, מערך, קפיצות על ציר המספרים, חיבור חוזר, שטח ופירוק (למשל 7×8 = 7×5 + 7×3).
  - **תרגול יומי**: 12 תרגילים שנבחרים לפי חזרה מרווחת. תרגיל שטועים בו חוזר מהר, ותרגיל שכבר יודעים חוזר לעיתים רחוקות. כל טעות מציגה מיד המחשה עם כפתור "תראו לי בדרך אחרת".
  - **המפה שלי**: טבלת 10×10 שנצבעת מאדום לירוק.
- **אותיות וקריאה באנגלית** (הלל ונירי)
  - **מכירים את האותיות**: כל אות ב-4 דרכים: תמונה ומילה, איך היא נשמעת (בעברית: B ← בּ), גדולה וקטנה בכמה גופנים (כולל טיפים ל-b/d/p/q), וכתיבה עם האצבע על המסך. יש השמעה קולית באנגלית.
  - **תרגול אותיות**: שומעים ובוחרים, מתאימים גדולה לקטנה, ומזהים באיזו אות מתחילה מילה. המסיחים הם אותיות שקל להתבלבל ביניהן. סדר הלימוד: S A T P I N, כמו בשיטות הפוניקה.
  - **מחברים צלילים**: c-a-t עם הצליל העברי מתחת לכל אות, ואז "לחבר!" מראה cat, תמונה, הקראה ופירוש. 32 מילים.
  - **מילים שרואים הרבה**: 40 מילים נפוצות (the, is, and…) עם הקראה ופירוש.
  - **תרגול קריאה**: קוראים מילה ובוחרים תמונה, שומעים ובוחרים איך כותבים, ומתאימים מילה לפירוש שלה.
- **דקדוק באנגלית** (איתמר)
  - **הווה פשוט (Present Simple)**: הסבר על מבנה המשפט בחיוב ובשלילה בשלוש דרכי המחשה (צ'יפים צבעוניים, עץ החלטה לפי הנושא, השוואת חיוב מול שלילה), ותרגול שבו בוחרים את המשפט הנכון.
- **שברים** (נירי)
  - **להכיר שברים**: כל שבר ב-4 דרכים: עוגה, פס, ציר מספרים וקבוצה.
  - **שבר כחלק משלם**: מתאימים ציור לשבר ולהפך.
  - **שם השבר**: חצי, שליש, רבע, חמישית... וגם בכיוון ההפוך.
  - **חיבור שברים**: מחברים שני שברים עם אותו מכנה, כולל מעבר לשלם (למשל 2/3 + 2/3 = 1 1/3).
  - **גדול, קטן או שווה**: משווים בין שני שברים, כולל שברים שווים בכתיב שונה (1/2 לעומת 2/4).
- **הכתבה** (נירי): רשימת המילים מהכיתה (בחירות ודמוקרטיה).
  - **לומדים את המילים**: כל מילה ב-4 דרכים: בהברות, מצליל לאותיות (איזה אותיות כותבות כל צליל), מלכודות (ח ולא כ, ט ולא ת, וו כפולה, אותיות סופיות...) ובמשפט. יש הקראה בעברית כשלמכשיר יש קול עברי.
  - **תרגול**: שומעים את המילה ובוחרים איך כותבים אותה, מול כתיבים שגויים שקל להתבלבל בהם.
  - **הכתבה**: האפליקציה מקריאה את המילים (מילה, משפט, מילה), כותבים על דף, ובסוף מצלמים את הדף ומקבלים ציון. בלי קול עברי, מבוגר מקריא (כפתור ״👀 למבוגר שמקריא״). אפשר לתקן כל סימון ✓/✗, ואם הבדיקה האוטומטית לא זמינה, בודקים לבד מול הרשימה.
- **סטטיסטיקות להורים** (כפתור "📊 סטטיסטיקות להורים" בדף הבית, או מההגדרות): לכל ילד רואים מתי תרגל לאחרונה, ימי תרגול, ימים ברצף, תרגילים ודקות בשבוע (עם השוואה לשבוע שעבר), דיוק בניסיון הראשון, לוח ימי תרגול ל-12 שבועות, גרף שבועי, קצב ההתקדמות (פריטים בשליטה לאורך זמן), פילוח לפי נושא, פריטים שכדאי לחזק וסיבובים אחרונים. כשהקודים פעילים, רק ההורה רואה את הדף.
- **שמירה בגיט**: ההתקדמות נשמרת במכשיר וגם בקובץ `progress/<ילד>.json` בריפו, ועוברת בין מכשירים. כניסה עם קוד אישי היא אפשרות שאפשר להדליק.

**עיקרון המחשה:** לכל מושג יש לפחות 3 דרכי המחשה שונות, וכפתור "תראו לי בדרך אחרת" שעובר ביניהן.

## אתר ופריסה (Vercel)
- **אתר הילדים (פרודקשיין)**: https://school-pearl-eight.vercel.app, מתוך הענף `main`.
- **גרסאות בדיקה**: כל שינוי חדש מגיע בענף נפרד, ו-Vercel בונה ממנו גרסה עם כתובת משלה (רואים אותה ב-Vercel תחת **Deployments**). בודקים שם, ורק אחרי אישור ממזגים ל-`main`.
- **ההתקדמות נשמרת בנפרד**: האתר האמיתי כותב לענף `progress`, וגרסאות הבדיקה לענף `progress-preview`. תרגול בגרסת בדיקה לא נוגע בהתקדמות האמיתית של הילדים.

### הגדרת שמירה בגיט (פעם אחת)
1. **טוקן לגיט**: ב-GitHub נכנסים ל-**Settings → Developer settings → Fine-grained tokens → Generate new token**. Repository access: רק `guyos2/school`. Permissions: **Contents: Read and write**.
2. **ב-Vercel**: ב-**Settings → Environment Variables** מוסיפים `GH_TOKEN` עם הטוקן, מסומן ל-Production ול-Preview.
3. **Deployments → Redeploy**.

כרגע **הכניסה היא בלי קוד**: לוחצים על התמונה של הילד ומתחילים. ההתקדמות נשמרת בגיט ועוברת בין מכשירים.

### בדיקת הכתבה מצילום (פעם אחת)
הבדיקה של הדף המצולם נעשית ב-Claude. ב-Vercel מוסיפים `ANTHROPIC_API_KEY` (מפתח מ-console.anthropic.com) ל-Production ול-Preview, ועושים Redeploy. בלי המפתח ההכתבה עובדת, והבדיקה נעשית ידנית.

### הפעלת קודים בכניסה (לא חובה, לעתיד)
מוסיפים ב-Vercel ארבעה משתנים ועושים Redeploy:
- `LOGIN_CODES` = `on`
- `TOKEN_SECRET`: מחרוזת אקראית ארוכה, שהשרת משתמש בה כדי לחתום על הכניסות
- `USERS`: קוד לכל ילד וסיסמה להורה, למשל `{"hillel":"1234","niri":"5678","itamar":"2468","dani":"1357","parent":"MySecret2026"}`. כדאי לכתוב את השורה במחשב, כי מקלדת של טלפון עלולה להחליף את המירכאות במירכאות מעוגלות.

עם קודים: ילד רואה רק את עצמו, הורה רואה את כולם, והמכשיר זוכר את הכניסה לשנה. כדי לנתק את כל המכשירים מחליפים את `TOKEN_SECRET`.

בטלפון בוחרים "הוספה למסך הבית", והאתר ייראה כמו אפליקציה.
