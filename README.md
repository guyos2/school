# לומדים בבית 📚

אפליקציית לימוד וחזרה לילדים: הלל (ד׳), נירי (ה׳), איתמר (ח׳) ודני (גן חובה).
אפליקציית ווב אחת עם פרופיל לכל ילד, שרצה בטלפון, בטאבלט ובמחשב. כל ההתקדמות נשמרת בגיט ועוברת בין מכשירים.

## מה כבר עובד
- **לוח הכפל** (הלל ונירי)
  - **ללמוד ולראות**: כל תרגיל ב-5 דרכי המחשה: קבוצות, מערך, קפיצות על ציר המספרים, חיבור חוזר, שטח ופירוק (למשל 7×8 = 7×5 + 7×3).
  - **תרגול יומי**: 12 תרגילים שנבחרים לפי חזרה מרווחת. תרגיל שטועים בו חוזר מהר, ותרגיל שכבר יודעים חוזר לעיתים רחוקות. כל טעות מציגה מיד המחשה עם כפתור "תראו לי בדרך אחרת".
  - **המפה שלי**: טבלת 10×10 שנצבעת מאדום לירוק.
- **סנכרון**: ההתקדמות נשמרת במכשיר ונדחפת לקובץ `progress/<ילד>.json` בענף `progress` בריפו.

**עיקרון המחשה:** לכל מושג יש לפחות 3 דרכי המחשה שונות, וכפתור "תראו לי בדרך אחרת" שעובר ביניהן.

## הקמה (פעם אחת)

### 1. אתר
ב-GitHub: **Settings → Pages → Deploy from a branch → `main` / root**.
אחרי דקה האתר זמין בכתובת `https://guyos2.github.io/school/`. בטלפון אפשר לבחור "הוספה למסך הבית" והוא ייראה כמו אפליקציה.
> אם הריפו פרטי, GitHub Pages דורש מנוי GitHub Pro. אפשרות אחרת היא לפרסם דרך Cloudflare Pages (חינם).

### 2. טוקן לגיט
ב-GitHub: **Settings → Developer settings → Fine-grained tokens → Generate new token**
- Repository access: רק `guyos2/school`
- Permissions: **Contents: Read and write**

### 3. שרת סנכרון (Cloudflare Workers, חינם)
```bash
cd worker
npx wrangler login
npx wrangler secret put GH_TOKEN     # הטוקן מסעיף 2
npx wrangler secret put FAMILY_KEY   # סיסמת משפחה שתבחרו
npx wrangler deploy
```
הפקודה האחרונה מדפיסה כתובת בסגנון `https://school-sync.<שם>.workers.dev`.

### 4. בכל מכשיר
באפליקציה: ⚙️ → מזינים את כתובת השרת ואת סיסמת המשפחה → "שמירה וסנכרון".
