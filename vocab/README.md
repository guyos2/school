# מילים בכיתה 📚 (שם זמני)

אפליקציה להורים: אוצר מילים וזמנים באנגלית לכיתות ד׳–ז׳, לפי מה שלומדים בכיתה.
זו אפליקציה נפרדת מ"לומדים בבית" (האפליקציה המשפחתית בשורש הריפו). היא חיה בתיקייה `vocab/` ונפרסת כפרויקט Vercel נפרד.

## מה יש בשלד
- **הורים**: הרשמה וכניסה עם מייל וסיסמה. הוספת ילדים עם שם, כיתה (ד׳–ז׳) ודמות. עריכה ומחיקה.
- **לינק אישי לכל ילד**: נכנסים ישר לתרגול, בלי סיסמה. ההורה שולח אותו בוואטסאפ, בכפתור השיתוף של הטלפון או ב-QR. המכשיר זוכר את הילד. אם הלינק דלף, ההורה מחליף אותו והישן מפסיק לעבוד.
- **לינק משפחתי** (כשיש יותר מילד אחד): מכשיר משותף מקבל מסך "מי מתרגל?".
- **לימוד חופשי**: מאגר מילים לפי כיתה. בשלד יש מאגר התחלתי של 40 מילים לכל כיתה, והמאגר המלא יגיע בהמשך. מילים חדשות נכנסות מהכיתה של הילד ומעלה, לפי ההצלחה:
  - מעט מילים חדשות כשהתשובות האחרונות פחות טובות או שהרבה מילים עוד לא יציבות
  - יותר מילים חדשות כשהולך טוב
  - כשהמילים של הכיתה נגמרות, ממשיכים למילים של הכיתה הבאה
- **ביטחון שמילה ידועה**: התרגיל נהיה קשה יותר ככל שהמילה ידועה יותר: בחירת פירוש, בחירת המילה באנגלית, כתיבת הפירוש. מילה נחשבת "ידועה היטב" רק אחרי שהילד כתב את הפירוש נכון כמה פעמים, ברווחים של כמה ימים. אחרי זה היא חוזרת רק לעיתים רחוקות (40 יום, ואחר כך 100), ולא ממלאת את התרגול היומי. תרגול לפני הזמן לא מקדם מילה. "כבר מכירים את המילה" מדלג על השלבים הקלים רק אחרי שהילד כתב את הפירוש נכון.
- **הכנה למבחן**: ההורה מזין כותרת, תאריך ורשימת מילים (מילה ופירוש בכל שורה, או רק מילה שכבר נמצאת במאגר). עד המבחן המשימה היומית היא רק המילים של המבחן:
  - המילים החדשות מתחלקות לימים, כך שכולן נפגשות לפני המבחן
  - החזרות מתקצרות כדי שיחזרו לפני התאריך
  - הילד וההורה רואים אחוז מוכנות
  - לימוד חופשי נשאר זמין רק אם הילד בוחר בו
- **מסך הילד**: "המשימה של היום" או "מתכוננים למבחן", מילים שיודעים היטב, מילים בלימוד, ימים ברצף, הרמה, ו"המילים שלי".
- **תרגול**: הקראה באנגלית, ארבע אפשרויות, וכתיבת פירוש שמקבלת כמה פירושים (כולל "התשובה שלי נכונה גם כן"). בטעות רואים את התשובה הנכונה, כרטיס מילה ומשפט, והמילה חוזרת בסוף הסיבוב.
- **התקדמות להורה**: מילים ידועות, בלימוד, רצף, תרגול אחרון ומילים לחיזוק. דף הסטטיסטיקות המלא מהאפליקציה המשפחתית יועבר בהמשך.
- **שמירה**: ההתקדמות נשמרת במכשיר מיד ומסתנכרנת לשרת. בין מכשירים, הגרסה החדשה של כל מילה גוברת.

## השלבים הבאים
| שלב | תוכן |
|---|---|
| 1 | ✅ שלד: חשבונות, ילדים, לינקים, לימוד חופשי, הכנה למבחן מרשימה, התקדמות |
| 2 | מאגר מילים מלא לכיתות ד׳–ז׳ (בערך 2,000–3,000 מילים), ואחר כך ספרי JET לפי יחידות |
| 3 | העשרת מילים: משפטים, משפט להשלמה, משפחת מילים ושלוש המחשות לכל מילה, כמו ב-`js/viz/vocab.js` של האפליקציה המשפחתית |
| 4 | מילים מהכיתה מצילום: Claude קורא את הדף, והמילים נכנסות לתרגול (התמונה לא נשמרת) |
| 5 | הכנה למבחן מתיאור חופשי: כתיבה, הקלטה או צילום, והמערכת מבינה מילים, נושאי דקדוק ותאריך |
| 6 | זמנים: Present Simple, Present Progressive, Past Simple, עם תרגילים שנבנים מהמילים של הילד |
| 7 | מבחן מיקום, מבחן דמה לפני מבחן, ודף הסטטיסטיקות המלא |

## הרצה מקומית
```bash
cd vocab
npm install
npm run dev        # http://localhost:3000, נתונים בקובץ .data/db.json
npm test           # בדיקות השרת והתכנון. עם TEST_DATABASE_URL הן רצות גם מול Postgres
```

## פריסה ב-Vercel (פרויקט חדש, לא נוגעים באפליקציה המשפחתית)
1. ב-Vercel: **Add New → Project**, ובוחרים את אותו ריפו (`guyos2/school`). ב-**Root Directory** בוחרים `vocab`. Framework: **Other**.
2. **Storage → Create Database → Neon (Postgres)** ומחברים לפרויקט. זה יוצר את המשתנה `DATABASE_URL`. כדאי לבחור באפשרות של ענף נפרד לכל Preview, כדי שבדיקות לא ייגעו בנתונים האמיתיים. הטבלאות נוצרות לבד בהפעלה הראשונה (`db/schema.sql`).
3. **Settings → Environment Variables**: מוסיפים `TOKEN_SECRET` עם מחרוזת אקראית ארוכה (למשל הפלט של `openssl rand -base64 32`).
4. כל ענף מקבל כתובת Preview משלו. ממזגים ל-`main` רק אחרי אישור.

## מבנה
- `index.html`, `css/style.css`, `js/app.js`: נתב (hash). מסכי הורה ב-`js/parent.js`, מסכי ילד ב-`js/kid.js`.
- `js/plan.js`: בניית המשימה היומית, חופשית או למבחן. `js/srs.js`: חזרה מרווחת עם 8 תיבות. `js/practice.js`: מסך התרגול.
- `js/bank.js` ו-`content/bank/grade<N>.json`: מאגר המילים, ופענוח רשימת מילים של הורה.
- `js/store.js`: התקדמות במכשיר וסנכרון. `js/api.js`: קריאות לשרת וזיכרון הלינקים במכשיר.
- `js/ui.js`, `js/speech.js`, `js/meaning.js`: הועתקו מהאפליקציה המשפחתית.
- `api/_server.js`: כל לוגיקת השרת. `api/_db.js`: Postgres, או קובץ JSON מקומי. `api/main.js` ו-`vercel.json`: הכניסה ב-Vercel.
